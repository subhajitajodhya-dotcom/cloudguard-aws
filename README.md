## 🚀 Projects

### ☁️ [Cloud Cost Optimization on AWS](https://github.com/subhajitajodhya-dotcom/cloud-cost-optimization-aws)

Provisions AWS infrastructure with **Terraform**, runs a containerized app with **Docker**, monitors the server with **Prometheus and Grafana**, and uses **PowerShell scripts** with the AWS CLI to stop idle servers, find unused resources and report cost.

**Tech:** `AWS` `Terraform` `Docker` `Prometheus` `Grafana` `PowerShell`

**What it shows:** Infrastructure as Code (8 AWS resources), containers, live monitoring dashboards, and cost-saving automation, tested end to end on a real AWS account.
